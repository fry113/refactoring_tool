## Назначение проекта

Утилита рефакторинга кода на C++. Позволяет автоматизировать процесс улучшения качества исходного кода, исправления распространенных ошибок и улучшения его стиля.

### Возможности:
- Добавление ключевых слов `virtual` к невиртуальным деструкторам.
- Добавление атрибута `override` к методам, которые переопределяют виртуальные методы базовых классов.
- Добавление ссылок в циклы range-for для переменных, которые не являются фундаментальными типами или auto с выводом во встроенный тип.

### Пример использования:
```bash
./build/refactor_tool ../tests_data/for_refactor.cpp
```

## Структура проекта

- **include/** - заголовочные файлы.
- **src/** - реализация утилиты рефакторинга.
- **tests/** - модульные тесты на GoogleTest.
- **CMakeLists.txt** - файл конфигурации системы сборки CMake.
- **README.md** - основная документация проекта.

## Тестирование

Для запуска тестов используйте следующие скрипты:

1. **check_refactor.sh**: Проверяет базовые сценарии рефакторинга.

    ```bash
    ./check_refactor.sh
    ```

2. **check_perf.sh**: Производит профилирование производительности до и после рефакторинга, используя `perf`.

    ```bash
    ./check_perf.sh
    ```

3. **check_asan.sh**: Проверяет наличие утечек памяти с помощью AddressSanitizer (ASAN).

    ```bash
    ./check_asan.sh
    ```

### Тесты

Проект использует GoogleTest для модульного тестирования. Вы можете запустить тесты следующими способами:

- Через `ctest`:

    ```bash
    ctest --test-dir build --output-on-failure
    ```

- Используя расширение **C++ TestMate** в VS Code.

## Сборка проекта

Для сборки проекта используйте CMake:

```bash
mkdir -p build
cd build
cmake ..
make
```
